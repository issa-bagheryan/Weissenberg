A local document processing app for extracting and validating structured information from invoices, receipts, contracts, and forms. Built as a learning project to explore document processing, OCR, data extraction, and validation.

The app processes documents, extracts relevant fields, identifies missing or inconsistent information, and lets users review and correct the results before exporting them to Excel, CSV, or JSON. Everything runs locally, without external APIs.

Things I worked on:

- Exploring and designing the document processing workflow
- Working with document parsing and OCR using Tesseract
- Defining extraction and validation logic for different document types
- Working with data normalisation for dates, amounts, and currencies
- Designing validation rules for missing fields, inconsistent totals, invalid dates, and duplicate invoices
- Exploring batch processing and structured data export
- Working with both web app and command-line execution
- Understanding the application's modular architecture and how its components interact

The project was developed with extensive assistance from Claude, which generated most of the code, including the frontend and significant parts of the backend. My focus was on defining the functionality, guiding implementation, and understanding the engineering decisions behind the application.
